# Stillwater Retreat

A concept boutique retreat with an interactive room and stay planner.

An original, clearly labeled concept project. Booking, signup and cart interactions are demonstrations; they do not place orders or reservations.

## Run

Node.js 22 or newer.

```sh
npm install
npm run build
npm run dev
```

## Features

- Original hospitality concept landing page
- Room selection, gallery and sample stay price calculation
- Local booking demonstration with date validation

## Embed

Use `?embed=1&theme=light` (or `dark`) for the compact homepage demo. Theme follows the operating system by default, with an optional saved preference.

## Deployment

Vercel serves the generated `dist` directory.
